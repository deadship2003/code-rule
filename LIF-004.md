## LIF-004: Git Commit Identity [Process Standard · universal commits | Effective 2026-09-07]

> Origin: 2026-09-07 requirement — all git commits must use Author
> Deadship2003, Email Deadship2003@gmail.com; any other identity
> information is forbidden.

Scope: all commit operations, in all projects and all git repositories.

### Implementation Rules

- Author and Committer fields are always: Name `Deadship2003`, Email
  `Deadship2003@gmail.com` (capital D in the local part, never
  lowercase).
- `git config user.name / user.email` keep this value in both `--global`
  and every repository scope.
- No other identity information of any kind: including `Co-Authored-By:
  Claude Code` and any additional signature trailers.
