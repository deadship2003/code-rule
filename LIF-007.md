## LIF-007: Global Debug Flag --debug [Technical Standard · personal enhancement | Effective 2026-09-07]

Scope: all programs implementing the LIF-006 service-management CLI,
in any IT development project. **A personal enhancement — optional and
non-standard** — LIF-006 is the systemd standard implementation; this
entry is its enhancement layer; the two stay as separate entries and
are not merged.

### Implementation Rules

- **Syntax**: `prog run --debug`, scope flags trailing as options
  (`prog run --debug --system`); must not be combined with the
  service-management subcommands (start/stop/restart/install/uninstall/
  status/enable/disable).
- **Run mode**: blocking foreground execution of business logic;
  stdout/stderr go straight to the console.
- **Environment alignment**: automatically reads the .service file of
  the matching scope (user/system) and restores the working directory
  and all environment variables, simulating the production runtime
  context.
- **Instance mutual exclusion**: before starting, probe the target
  service's state; if the systemd-managed instance is running, refuse
  to start, so as to avoid multi-instance conflicts.
- **Signal handling**: Ctrl-C (SIGINT) triggers graceful shutdown,
  consistent with the background-managed exit behavior.
- **Log viewing**: no built-in log aggregation command; log
  investigation uses journalctl, tail and other system-native tools.
